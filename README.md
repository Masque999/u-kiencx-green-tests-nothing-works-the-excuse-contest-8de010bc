# Green Tests, Nothing Works: The Excuse Contest

One original excuse for green tests and broken software, at most 140 characters.

Entry: `All tests green, nothing works: the tests test the mocks, the mocks mock the code, and the code mocks me.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
